    Convert HEIC to JPG or PNG

    Drop the HEIC (.heic or .heif) files from your iPhone into the box above, choose JPG or PNG, and press Convert. You can add many files at once and download them as a single ZIP. Photo orientation (for example, a portrait shot stored rotated) is applied as recorded in the file.

    How it works

    HEIC is a container (HEIF) holding images compressed with HEVC, the same codec family used for video. This page does not bundle an HEVC decoder. Instead:

    1. Where the browser can open HEIC itself (Safari 17 and later, per Apple), the page lets it do so.
    2. Otherwise the page parses the HEIF container in JavaScript (about 250 lines: item info, locations, properties, grid layout, rotation and cropping), builds the HEVC codec string from the file, and passes each tile to the browser's WebCodecs VideoDecoder. The browser or OS does the actual HEVC decoding. The tiles are then drawn onto a canvas in order.
    3. If neither works, the page shows the file name and the reason instead of failing silently.

    Because no codec is bundled, whether HEIC works depends on your browser and device:

    • Safari (iPhone, iPad, Mac): Safari 17 and later can open HEIC itself. Tested in Safari on an iPhone simulator (iOS 26.5), including orientation.
    • Chrome on macOS: tested and working (Chrome 156). HEVC is decoded through WebCodecs.
    • Chrome and Edge on Windows, Chrome on Android: expected to work if the GPU or device supports HEVC decoding (Chrome 107 and later, based on public documentation; not tested by us). Windows may need the HEVC video extension from Microsoft.
    • Firefox and Linux: often will not work (Chrome on Linux works only with some GPUs). Firefox has not been tested by us. When HEIC cannot be decoded, the page shows the file name and the reason.

    HEIC files are processed in the browser like every other format; the page's code does not send them anywhere.

    If your HEIC will not open

    The quickest fix is to open this page in Safari, or in Chrome on macOS. To make your iPhone save future photos as JPEG, go to Settings, Camera, Formats and choose "Most Compatible". For photos you already have, sharing from the Photos app can send them as JPEG (for example by Mail or AirDrop; option names vary by iOS version). Note that when you pick a photo from the library in Safari on iPhone, iOS sometimes converts it to JPEG before handing it over, in which case no HEIC handling is needed.

    Convert WebP to JPG

    Drop your WebP files into the box, choose JPG, and press Convert. Animated WebP keeps only its first frame. JPG cannot hold transparency, so transparent areas are filled with the background colour you pick (white by default).

    Convert AVIF to JPG

    The steps are the same. Whether AVIF can be read depends on your browser. Current versions of Chrome, Firefox and Safari support it; older ones may not, and the file is then listed as failed. Update your browser or try another one.

    Convert WebP to PNG

    Choose PNG as the output. PNG keeps transparency, so transparent WebP stays transparent. PNG is lossless, so there is no quality setting. Note that if the WebP was lossy, converting to PNG does not restore quality and the file is usually larger.

    Convert PNG to WebP

    Choose WebP and adjust the quality slider. For photos, WebP is often much smaller than PNG, and transparency is kept. Some browsers (older Safari, for example) cannot export WebP; in that case the page stops with an error at conversion time.

    Limits and notes

    • HEIC works only where the browser can decode HEVC (see "How it works" above).
    • Colour: HEIC images are exported as the browser renders them in sRGB. HDR and wide-gamut photos (such as Display P3) are mapped to nearby sRGB colours, so brightness and saturation can shift slightly. The page passes the file's colour information (nclx) to the decoder when it can, but does not use embedded ICC profiles on the WebCodecs path.
    • HEIC alpha and depth data are not used. Portrait-mode depth maps and extra images in multi-image HEIC files are ignored; only the primary image is exported. The video part of Live Photos is not included.
    • HEIC files that use unusual features are not supported: storage method 2, derived images (iden, iovl) and non-HEVC tiles. The page reports the reason. We have tested files generated by macOS sips; not every rotation, mirror or alpha case has been tested.
    • Very large images, such as 48-megapixel HEIC, are scaled down to the phone browser's canvas limit (about 16.7 megapixels) when needed, and the list says so.
    • Metadata (EXIF, GPS and so on) is removed, because images are redrawn before export.
    • Images over 100 megapixels (about 10,000 x 10,000) are not loaded. Large conversions can fail because of browser limits, especially on phones; the file name is then listed.
    • Up to 300 files per batch. ZIP output is limited to about 4 GB.
    • Characters not allowed in file names (/ \ : * ? " < > |) are replaced with _.
    • AVIF output is offered only if your browser can export AVIF.

    FAQ

    Are my files really not uploaded?

    Not by this page's code. It works offline, so you can check: load the page, disconnect from the network, and convert. You can also watch the network tab in your browser's developer tools.

    Why does HEIC not work in my browser?

    HEIC photos use the HEVC codec. This page ships no HEVC decoder, so it relies on one in your browser or operating system. If yours does not provide one (Firefox, some Linux setups, Windows without the HEVC extension), HEIC cannot be decoded. Try Safari, or Chrome on macOS.

    Will transparent images get a black background as JPG?

    No. JPG cannot store transparency, so the page paints your chosen background colour (white by default) before exporting. Change it in the background colour field if you want something else.

    Is EXIF data or the location kept?

    No. Every image is redrawn on a canvas and re-encoded, so all metadata is dropped. This also means GPS location is not carried into the converted file.

    What quality setting should I use?

    The default of 85 usually gives a small visible loss for JPG and WebP. Lower it for smaller files; raise it if you see smearing around text or line art. JPG and WebP are lossy, so converting a file more than once reduces quality each time.
