PDFを結合(無料・アップロードなし)

複数のPDFと、JPG・PNGなどの画像を、好きな順に並べて1つのPDFにまとめます。PDFは「1-3,5」のようにページを指定して、必要な部分だけ入れられます。

このページのコードは、ファイルをどこにも送信しません。 結合は、あなたのブラウザの中だけで行います。PDFや画像のアップロード、解析ツール、Cookieはありません。ただし、ブラウザ自体や拡張機能の通信までは、このページから保証できません。外に出したくない書類は、その点を踏まえてお使いください。

ここにPDFや画像をドロップ

または

PDF、JPG、PNG、WebP、GIFなどに対応。複数選択できます(200ファイル、合計500MBまで)。

1. 結合する順番

☰ をつかんでドラッグするか、↑ ↓ ボタンで順番を変えられます。上から順に1つのPDFになります。

    2. 出力の設定

    画像のページと、ファイル名

    画像はA4に、縦横比を保ったまま収めて中央に置きます。「元の大きさ」は、画像の1ピクセルを0.75ポイント(96dpi相当)にしたページを作り、余白を足します。PDFのページは、元の大きさのまま入ります。

    3. ダウンロード

    PDFをダウンロード

    PDFを結合したい(pdf 結合)

    結合したいPDFを上の枠に入れ、「結合する」を押すだけです。入れた順ではなく、一覧の順番で1つのPDFになるので、先に並べ替えてください。ソフトのインストールや会員登録は要りません。WindowsでもMacでも、iPhoneやAndroidのブラウザでも、同じように使えます。

    一部のページだけを入れたいときは、そのPDFの「ページ」欄に 1-3,5 のように書きます(1〜3ページと5ページ)。2- なら2ページ目から最後まで。空欄なら全ページです。同じファイルを2回追加して、別々の範囲を指定することもできます。

    JPGやPNGの画像をPDFにしたい(jpg pdf 変換)

    画像も同じ枠に入れられます。画像1枚が、PDFの1ページになります。スキャンや写真を撮った画像と、ほかのPDFを同じ一覧に混ぜて、まとめて1つにできます。JPGとPNGは、画像の中身を作り直さずにそのままPDFへ入れます(スマホで縦向きに撮った写真など、向きの情報があるJPGは、向きを直すために描き直します)。

    複数の画像を1つのPDFにまとめたい(画像 pdf まとめる)

    画像だけを何枚か入れて並べ、「結合する」を押します。紙の書類を撮った写真を1つのPDFにして、メールで送る、といった使い方です。ページの大きさは、A4に収める(縦横は自動)か、画像の元の大きさかを選べます。WebP、GIF、BMP、AVIFは、ブラウザで読み込めればJPGに描き直して入れます(透明な部分は白になります。GIFは最初の1コマ)。HEIC(iPhoneの写真)は、ブラウザが開ける環境(SafariやmacOSのChromeなど)でだけ入れられます。開けない場合は、HEIC・WebP・AVIFをJPGに一括変換で先に変えてください。

    確定申告のe-Taxに添付する書類をまとめるとき

    領収書、源泉徴収票、控除証明書などの写真やスキャンを、e-Taxにイメージデータとして添付する場合の条件を、国税庁の案内から引きます(確認日 2026-11-07)。

    • 形式: 「イメージデータで提出可能なデータ形式は、PDFのみです。」(JPGのままでは出せないため、このページで画像をPDFにします)
    • 解像度と色: 「解像度は200dpi相当以上」、階調は「256階調(いわゆる、グレースケール)以上」
    • 量: 「1送信当たりのデータ容量はPDFファイル合計で最大14.0MB、ファイル数は最大136ファイル」。追加送信を併用すると、最大11回の送信で154.0MB・1,496ファイルまで
    • パスワード保護されたPDFは添付できません(国税庁の案内に記載)

    出典: 国税庁 e-Tax「添付書類のイメージデータによる提出について」、同「送信可能なファイル形式やデータ容量などを教えてください」(更新日 令和6年1月4日)。

    手順の例: 書類を200dpi以上でスキャンするか、近くでピントを合わせて撮影し、必要なら連番リネームで順番を整え、この結合ページに入れて1つのPDFにします。結合後のファイルが14.0MBを超えるときは、2つ以上に分けて、それぞれ14.0MB以下にします。このツールは圧縮をしないので、サイズは元の合計とほぼ同じです。また、このツールは結果が200dpi相当かを判定しません。「A4に収める」を選ぶと、画像はページの大きさに合わせて拡大縮小されます。条件は改正されることがあるため、提出前に最新の案内を確認してください。

    関連ツール: HEIC・WebP・AVIFをJPGに一括変換 / 画像を指定KB以下に一括圧縮 / 画像のサイズ変更 / 画像の連番リネームとZIP保存

    制限と注意

    • パスワードで保護(暗号化)されたPDFは結合できません。パスワードを外す機能は、このページにはありません。Acrobatやプレビューなど、パスワードを知っている本人が使えるソフトで、保護を外して保存し直したものを入れてください。
    • 一度に扱えるのは200ファイル、合計500MBまでです。それ以上は分けて結合し、結果をもう一度結合してください。ブラウザのメモリ次第で、それより少なくても失敗することがあります(特にスマホ)。
    • 壊れたPDFや、PDFではないファイルは、一覧に入れず、理由を表示します。
    • ページの中身(文字、画像、フォント)はそのまま写します。ただし、結合しても容量は減りません。しおり(目次)、フォームの入力欄、注釈のリンクなどは、引き継がれないことがあります。署名付きPDFの署名は、結合すると無効になります。
    • 圧縮はしません。結合後のファイルは、元のファイルの合計とほぼ同じ大きさです。
    • ファイル名に使えない文字(/ \ : * ? " < > |)は _ に置き換えます。

    よくある質問

    本当にアップロードされませんか。

    結合のコードは、このサイトに置いたライブラリ(pdf-lib)だけで、外部への通信を行いません。ブラウザ自体や拡張機能の通信までは保証できません。

    1日の回数や容量の制限はありますか。

    回数の制限、会員登録、透かしはありません。1回の上限は、200ファイル・合計500MBです。上限は、ブラウザの安全のために置いたものです。

    パスワード付きのPDFは結合できますか。

    できません。暗号化されたPDFは、中身を読めないため、一覧に入れずに理由を表示します。パスワードを知っている場合は、別のソフトで保護を外して保存し直してから入れてください。パスワードを破る機能はありません。

    ページの順番を入れ替えたり、1ページずつ並べ替えたりできますか。

    並べ替えられるのは、ファイル単位です。1つのPDFの中のページを入れ替えたいときは、同じPDFを複数回追加し、それぞれにページ範囲(たとえば「3」「1-2」)を指定して並べてください。
